# カナつなぎパズル

ポケモンの名前だけでできたクロスワード型の穴埋めパズル。
先に「全マスが名前で埋まる答え」を生成してから出題するので、必ず解ける。

## あそびかた

GitHub Pages で公開しているページを開くか、`index.html` をブラウザで開くだけで遊べます（ビルド・サーバー不要、依存ゼロ）。

- 盤面はクロスワード状（十字や凸凹の形、最大70マス）で、名前は**10個固定**。**制限時間3分**いないにタテ・ヨコの並びをすべてポケモンの名前にすれば完成
- 一部の文字は最初から公開（ランダムで全体の約22%。どの並びにも最低1マスはあきが残る）
- パレットから文字を選ぶと「回答セット」に順番にたまる。セット内で文字の入れ替え可能（文字→文字クリックで入れ替え、同じ文字2回でパレットに戻す、文字→空き部分クリックで末尾へ移動）
- 盤面の開始マス→終わりマスをクリックすると区間に一気に置ける（埋まっているマスは飛ばす・逆順の区間も可）。1文字だけならワンクリック。自分で置いた文字はクリックで取り外せる
- 並びが埋まったのに名前でないときは赤表示
- 名前成立から**20秒いない**に次を成立させると「2連鎖！3連鎖！…」。正解ポップアップの表示中は連鎖猶予のカウントが停止し、「あと○秒で○連鎖」が小さく表示される。得点は文字数×10×連鎖数、クリアボーナス+100点
- なにもセットしていない状態であきマスをタップすると、そのマスを通る並びのヒント（図鑑説明文の全文）を表示
- 名前が成立するとポケモンの画像＋図鑑説明文入りポップアップを表示（画像は公式アートワーク→スプライト→プレースホルダの3段フォールバック、実行時に PokeAPI sprites リポジトリを参照しリポジトリには同梱しない）
- 時間切れ・「こたえを見る」で答えを盤面に表示し、答えられなかったマスを赤く強調。新しい問題は「つぎの問題へ」（または「新しい問題」）を押したときに生成される
- 「なまえの範囲」で対象を「第1世代まで」〜「ぜんぶ」から選べる（図鑑番号の累積フィルタ。選択は localStorage に保存され、変更すると新しい問題になる）

## しくみ

- `generator.js` — 答えの盤面を生成（DOM非依存）。種の名前を1つ置き、交差点を共有する名前をクロスワードの制約（交差以外で隣接しない・語の前後はあき）で追加していく。全ての極大な並びが名前になることが構成上保証される
- `main.js` — 出題（公開マスの選定・パレット化）と対局ロジック・UI

## データ

`names.js` は `pokemon-speed-quiz/src/data/pokedata.json`（PokeAPI 由来）から `scripts/gen-names.mjs` で生成。
カタカナと長音のみの名前 1016 件を収録（♂♀・数字・記号入りの名前は除外）。
再生成する場合は pokedata.json を更新してからスクリプトを実行すること（名前リストを AI に直接書かせない）。

`hints.js` は `scripts/sync-hints.mjs` で PokeAPI の GitHub 上の CSV から生成（API サーバーには接続しない・手動実行のみ・CI に入れない）。
種族値6つと日本語図鑑説明文を収録。日本語説明文が無い No.899 以降は「ぶんるい」または「タイプ」で代用。

## デプロイ

`main` ブランチへの push で GitHub Actions（`.github/workflows/deploy.yml`）が
リポジトリの静的ファイルをそのまま GitHub Pages に公開する。
ビルドは不要。データ生成スクリプト（`scripts/`）は CI では実行しない。
